# Groww mutual fund facts assistant

A facts-only assistant for four HDFC Mutual Fund Direct Growth schemes, plus the Groww steps for downloading a mutual-fund capital-gains statement. It quotes the loaded pages. It does not give investment advice.

> Facts only. No investment advice. Answers are short quotations of public pages on HDFC Mutual Fund schemes (Direct Plan, Growth) and official help or regulator pages. They are not a recommendation to buy, sell, or hold any scheme. Past performance is not shown here on purpose. Check the linked page before you act.

The same disclaimer is always visible on the page. The collapsed panel “How this answer was produced” shows the RAG stage for the current question. It is there for this milestone and is not a customer feature.

Hosted demo: https://groww-rag-beige.vercel.app

## Setup

Python 3.12 is what the hosted app uses (`.python-version`). A local 3.9 virtualenv can run the same code.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-ingest.txt
cp .env.example .env
```

Put `GROQ_API_KEY` in `.env`. That file is gitignored. `.env.example` has the same keys and an empty secret.

| Variable | Role |
| --- | --- |
| `LLM_PROVIDER` | `groq` by default. OpenAI, Anthropic, Gemini, and Mistral use the same `complete(system, user)` call when their SDK is installed from `requirements-providers.txt`. |
| `LLM_MODEL` | `qwen/qwen3.8-27b` |
| `GROQ_API_KEY` | Required for answers that reach the model. Refusals never call it. |
| `LLM_TEMPERATURE` | `0.1` |
| `LLM_REASONING_EFFORT` | `none` on Groq |

Chunk size, `top_k`, the embedding model name, and citation domains live in `config.yaml`. Changing the provider or model means editing `.env` only.

## Corpus

`sources/sources.csv` has six rows. Five are the Groww scheme and AMC pages. The sixth is the Groww Help article that actually contains the capital-gains download steps. The older capital-gain-report URL no longer includes them, so it is not in the list.

| id | Page |
| --- | --- |
| `hdfc-amc` | HDFC Mutual Fund overview |
| `hdfc-large-cap` | HDFC Large Cap Fund Direct Growth |
| `hdfc-flexi-cap` | HDFC Flexi Cap Direct Plan Growth (the page slug still says equity fund) |
| `hdfc-elss` | HDFC ELSS Tax Saver Fund Direct Plan Growth |
| `hdfc-mid-cap` | HDFC Mid Cap Fund Direct Growth |
| `groww-help-capital-gains` | Section 80C help article, which states the Mutual Fund capital-gains download steps |

Figures are whatever those pages said on the fetch date. They are not constants in code.

## Commands

| Command | What it writes |
| --- | --- |
| `python -m app.cli scrape` | `data/raw/<id>/` |
| `python -m app.cli load` | `data/documents/documents.jsonl` |
| `python -m app.cli chunk` | `data/chunks/chunks.jsonl` |
| `python -m app.cli embed` | `data/embeddings/embeddings.jsonl` |
| `python -m app.cli index` | `data/chroma/` and the index stage in `data/pipeline.json` |
| `python -m app.cli pipeline` | Scrape through index, in order |
| `python -m app.cli ask "…"` | One answer and a trace under `data/traces/` |
| `python -m app.cli sample` | `eval/sample_qa.md` from eight real `POST /api/ask` calls |
| `uvicorn app.api:app --host 127.0.0.1 --port 8000` | The page at http://127.0.0.1:8000 |

`GET /api/health` stays 503 until every pipeline stage is `ok` and the embedding model name matches `config.yaml`. The page then says the index is not ready and does not call Groq.

Ingest embeddings use `sentence-transformers/all-MiniLM-L6-v2`. A question is embedded with the same model through fastembed, so the stored vectors stay usable without shipping PyTorch. Chroma is the local index from `index`. Question-time search reads `chunks.jsonl` and `embeddings.jsonl`.

## Sample file

`eval/sample_qa.md` is regenerated by `python -m app.cli sample`. It includes the three buttons on the page, one more scheme fact, an advice refusal, a ranking refusal, a missing-scheme question, and a PAN refusal. If the PAN appears in the saved trace, the command stops and does not write the file.

## Known limits

- One question per request. A follow-up such as “and the exit load?” needs the scheme name again.
- Advice, salary allocation, ranking, other fund houses, and account identifiers are refused before retrieval.
- A number in an answer has to appear in the cited chunk. If the draft fails that check, the page says the fact was not found.
- The first question in a fresh process loads MiniLM. Later questions are the ones to time. A warm ask is about a second once Groq is reachable over IPv4.
- On the hosted deploy, the function disk is read-only, so the trace file is not saved and `trace_path` is empty. Locally the trace is `data/traces/<id>.json`.
- Raw HTML, the Chroma folder, traces, and `.env` are not in git. The chunk and embedding files are, so the hosted app can answer without re-scraping.
